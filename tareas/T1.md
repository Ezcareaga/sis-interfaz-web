# T1 — Definición del Producto

## 1. Nombre del producto/servicio

**Careaga Dev** — Desarrollo de software a medida con inteligencia artificial integrada.

## 2. Descripción clara

Careaga Dev es una empresa de desarrollo de software que diseña e implementa soluciones digitales a medida para negocios. No vendemos un producto genérico que se adapta — estudiamos la operación del cliente, identificamos los puntos donde la tecnología y la inteligencia artificial generan impacto real, y construimos un sistema específico para ese negocio.

Los servicios incluyen: desarrollo de plataformas web (e-commerce, portales, sistemas internos), integración de IA aplicada al negocio (chatbots con acceso a datos reales, búsqueda semántica, paneles conversacionales), y automatización de procesos operativos (seguimientos, emails, reportes, tareas repetitivas).

Cada solución se construye con arquitectura limpia, código mantenible y deploy real — no mockups ni prototipos que mueren en una presentación.

**Stack tecnológico base:**

- **Backend:** Python + FastAPI, arquitectura hexagonal, PostgreSQL + pgvector, Redis, Celery.
- **Frontend:** Next.js 15 + TypeScript + Tailwind CSS + shadcn/ui.
- **IA:** Claude API, OpenAI Embeddings, LangChain (RAG, memoria conversacional, tools).
- **Automatización:** Celery + Redis (tareas programadas), Resend (emails transaccionales).
- **Deploy:** Vercel (frontend) + Dokploy en VPS (backend, BD, servicios).

## 3. Público objetivo

- **PyMEs paraguayas** que quieren digitalizar su operación pero no tienen equipo técnico propio y necesitan una solución que se ajuste a su negocio, no al revés.
- **Empresas medianas** que ya tienen sistemas pero necesitan integrar inteligencia artificial o automatizar procesos manuales que consumen tiempo y generan errores.
- **Emprendedores y comerciantes** que venden por WhatsApp o Instagram y necesitan una plataforma profesional construida para su modelo de negocio específico.

Ubicación principal: Ciudad del Este, Asunción, Encarnación. Sectores: comercio, servicios, logística, contabilidad.

## 4. Problema que resuelve

Las PyMEs en Paraguay enfrentan una disyuntiva:

1. **Software genérico que no se adapta.** Usan plataformas estándar (Shopify, WooCommerce, sistemas enlatados) que cubren el 70% pero dejan afuera las particularidades de su operación. Terminan con planillas de Excel y procesos manuales para cubrir el otro 30%.
2. **Desarrollo custom inalcanzable.** Contratar una software factory tradicional es caro, lento y el resultado muchas veces no incluye las capacidades que hoy hacen la diferencia — IA, automatización, búsqueda inteligente.
3. **Tareas manuales que no escalan.** Responder consultas de clientes, dar seguimiento post-venta, generar reportes, actualizar stock — todo se hace a mano. Funciona con 10 clientes, se rompe con 100.

El resultado: negocios que pierden ventas por fricción, pierden clientes por falta de seguimiento y pierden tiempo en tareas que una máquina hace mejor.

## 5. Propuesta de valor

Careaga Dev construye soluciones a medida donde la inteligencia artificial no es un agregado cosmético — es parte de la arquitectura desde el día uno.

- **Soluciones específicas, no adaptaciones genéricas.** Cada sistema se diseña para el modelo de negocio del cliente. Un e-commerce de regalería no se resuelve igual que un portal de servicios contables.
- **IA que trabaja con datos reales del negocio.** Chatbots que consultan stock, paneles donde el dueño pregunta "¿cuánto vendí esta semana?" y obtiene una respuesta real, búsqueda semántica que entiende intención — no solo palabras.
- **Automatización del ciclo completo.** Desde la captación del cliente hasta el re-engagement post-compra: confirmaciones, seguimiento de envíos, solicitud de reseñas, cross-sell, lead scoring. Todo automático, personalizado y medible.
- **Código profesional con deploy real.** Arquitectura hexagonal, tests, CI/CD, documentación. El cliente recibe un sistema en producción con URL accesible, no un prototipo.
- **Stack moderno y mantenible.** Python + FastAPI + Next.js + PostgreSQL. Tecnologías con comunidad activa, documentación sólida y talento disponible para escalar el equipo a futuro.

**Diferenciador:** En Paraguay no existe un servicio que combine desarrollo a medida + IA integrada + automatización de negocio a un precio accesible para PyMEs. Las software factories tradicionales no integran IA. Los freelancers que usan IA no tienen arquitectura profesional. Careaga Dev es las dos cosas.

## 6. Preguntas frecuentes

**¿Qué tipo de soluciones desarrollan?**
Plataformas web a medida: e-commerce, sistemas internos, portales de clientes, dashboards de gestión. Cada solución puede incluir chatbots inteligentes, búsqueda semántica, automatización de procesos y paneles conversacionales según lo que necesite el negocio.

**¿Cómo funciona la integración de IA en mi negocio?**
Analizamos qué procesos del negocio se benefician de IA — atención al cliente, búsqueda de productos, generación de reportes, seguimiento de ventas. Luego integramos modelos de lenguaje con acceso directo a los datos reales del negocio, para que las respuestas sean precisas y útiles, no genéricas.

**¿El chatbot realmente puede responder sobre mi stock y mis productos?**
Sí. No es un bot de preguntas frecuentes con respuestas pre-armadas. El chatbot tiene herramientas que consultan la base de datos en tiempo real: stock actual, precios, características, comparaciones entre productos. Responde con datos reales del momento.

**¿Qué incluyen las automatizaciones?**
Depende del negocio. Ejemplos concretos: confirmación automática de compra, notificación de envío con tracking, solicitud de reseña post-compra, emails de re-engagement para clientes inactivos, alertas de stock bajo, reportes periódicos automáticos. Todo configurable y medible.

**¿Necesito tener conocimientos técnicos para usar el sistema?**
No. Los sistemas se diseñan para que el dueño del negocio los administre sin depender de un programador. Incluyen paneles intuitivos y, cuando aplica, administración por lenguaje natural — se puede preguntar "¿cuáles fueron mis productos más vendidos este mes?" y obtener la respuesta directamente.

**¿Cuánto tiempo toma desarrollar una solución?**
Depende del alcance. Un e-commerce con IA integrada y automatizaciones completas toma entre 8 y 12 semanas. Soluciones más acotadas como una landing page con chatbot o la automatización de un proceso específico pueden estar listas en 3 a 4 semanas.

**¿Qué pasa después de la entrega? ¿Hay soporte?**
Sí. Se incluye un período de soporte post-entrega para ajustes y correcciones. Además se ofrecen planes de mantenimiento mensual para actualizaciones, monitoreo del sistema y soporte continuo.

**¿Mis datos están seguros?**
El sistema usa autenticación moderna, la base de datos corre en servidores con acceso restringido, y toda la comunicación va cifrada por HTTPS. Los datos del negocio no se comparten con terceros ni se usan para entrenar modelos de IA.

**¿Puedo ver un ejemplo de lo que construyen?**
Sí. Contamos con un e-commerce demo completamente funcional que incluye búsqueda semántica, chatbot con acceso al catálogo, automatización post-compra y panel de administración conversacional. Es una muestra directa de las capacidades que se aplican a cada proyecto cliente.
